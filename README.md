# Metric Sense

An offline-first React Native learning app for building quick intuition between metric and imperial measurements.

The first module is a temperature trainer for everyday environmental temperatures from freezing through about 100F. It starts with anchor points, adds more temperatures as the user learns, and keeps missed prompts in heavier rotation.

## Run locally

```sh
npm install
npm start
```

The app is built with Expo and stores practice progress locally on the device.
